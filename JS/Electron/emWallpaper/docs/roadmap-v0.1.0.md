# Grapher v0.1.0 里程碑

> 产品名：素材工厂（Creator's Bench）
> 定位：自媒体创作者的本地素材采集与管理工具
> 日期：2026-07-27
> 状态：planning

---

## 版本目标

v0.1.0 的北极星：**从一堆链接到本地可用的素材库，一步到位。**

下载器不值钱。v0.1.0 交付的是一个「素材采集→自动归库→本地浏览」的闭环工具。用户粘贴一批链接，应用自动下载并按项目归入文件夹，用户可以直接在应用内浏览、搜索、打开已下载的素材。

## 功能清单

### F1. 批量下载

**现状**：单 URL 输入，无并发控制，所有 chunk 全量并行（`Promise.all`）。
**目标**：

- 支持多行粘贴（textarea 输入，一行一个 URL）
- Worker 池并发控制：全局最大 worker 数上限，超过排队等待
- 同一文件的 chunk 共享 worker 池，避免单文件占满所有资源
- 速度显示：每任务实时速率（KB/s、MB/s）
- 失败重试：单 chunk 失败自动重试（最多 3 次），整体任务失败后用户可手动重试

**验收**：
- [ ] 粘贴 3 个 URL，3 个任务并行下载，每个速度独立显示
- [ ] 全局 worker 数不超过上限
- [ ] 模拟一个 chunk 失败，自动重试成功

### F2. 项目/文件夹管理

**现状**：所有文件平铺下载到同一个 `savePath`。
**目标**：

- 用户创建「项目」（本质是 `savePath` 下的子文件夹）
- 下载时可选择目标项目（默认"默认项目"）
- 项目列表在侧边栏显示，支持增删改
- 项目持久化到 Redux Persist

**验收**：
- [ ] 创建 3 个项目，选中"素材-七月"后下载文件，文件进入对应子文件夹
- [ ] 重命名项目，文件夹同步改名
- [ ] 删除项目时提示"仅删除项目记录"或"同时删除文件"

### F3. 素材浏览器

**现状**：无。下载完了只能看文件路径字符串。
**目标**：

- 以项目为维度浏览已下载素材
- 文件列表：文件名、大小、格式、下载时间
- 内置预览：视频缩略图、图片缩略图、文件基本信息
- 点击打开文件所在位置（调系统文件管理器）
- 搜索/筛选：按文件名、格式、日期范围

**验收**：
- [ ] 切换项目，文件列表随之刷新
- [ ] 视频文件显示缩略图
- [ ] 点击"打开位置"调起 Finder/资源管理器

### F4. 任务持久化与历史

**现状**：任务在内存中，刷新即丢失。
**目标**：

- 下载任务历史持久化到本地（localforage，不是 localStorage）
- 重启应用后历史任务列表恢复
- 已完成、失败、取消的任务可查看详情
- 已完成任务保留缩略图和文件路径信息
- 清除历史时可选是否同时删除文件

**验收**：
- [ ] 下载 2 个文件后重启应用，任务列表仍显示完成状态
- [ ] 清除历史，任务记录消失

### F5. 下载完成通知

**现状**：无任何通知。
**目标**：

- 下载完成时系统通知（Electron Notification API）
- 通知内容：文件名 + 保存路径
- 点击通知打开文件所在文件夹
- 应用后台时（最小化/不在焦点）仍弹通知

**验收**：
- [ ] 下载完成后弹出系统通知
- [ ] macOS 通知中心可见记录

### F6. 基础媒体信息（方向三起点）

**现状**：无。
**目标**：

- 下载完成后自动提取文件元信息：格式、大小、时长（视频）、分辨率（视频/图片）
- 在素材浏览中显示这些信息
- 通过 `ffprobe`（需检测是否安装）或纯 JS 解析实现
- 无 FFmpeg 时降级为仅显示文件大小

**验收**：
- [ ] 下载 mp4 文件后显示时长、分辨率、编码格式
- [ ] 未安装 FFmpeg 时仅显示文件大小，不报错

### F7. 系统托盘与后台运行

**现状**：关闭窗口即退出（macOS 除外）。
**目标**：

- 系统托盘图标 + 右键菜单（显示/隐藏、退出）
- 关闭窗口时最小化到托盘，不退出应用
- 托盘图标显示当前下载任务数角标（badge）

**验收**：
- [ ] 关闭窗口后应用仍在托盘运行
- [ ] 下载任务进行中关闭窗口，下载不中断
- [ ] 双击托盘图标恢复窗口

## 技术设计决策

### D1. Worker Pool

```
全局 poolSize = min(cpuCount - 1, 8)
每个下载任务占用固定 slot 数（默认 4）
同一任务 chunk 共享 slot，排队执行
```

选择原因：当前 `Promise.all` 全量并行在 100 个 chunk 时直接炸。池化后资源可控。

### D2. 任务持久化

- 存储层：`localforage`（已在依赖中，IndexedDB 优先）
- 持久化数据：任务 ID、URL、文件名、状态、进度、文件路径、创建时间
- 不持久化：worker 引用、运行时状态
- 切分 store：`DownloadReducer` 拆为 `DownloadTasksReducer`（持久化） + `DownloadRuntimeReducer`（内存）

### D3. 缩略图生成

- 视频缩略图：用 FFmpeg 取第一帧（依赖 FFmpeg）
- 图片缩略图：用 Canvas API 缩放（不需要 FFmpeg）
- 无 FFmpeg 时：视频显示通用图标
- 缩略图缓存到 `{savePath}/.grapher/thumbnails/`

### D4. 项目存储

- 项目列表存储在 Redux Persist（ConfigReducer 扩展）
- 磁盘结构：`{savePath}/{项目名}/{文件名}`
- 默认项目："默认素材"
- 项目文件夹在首次使用时懒创建

## 验证门禁

构建通过后，手动验收路径：

1. `yarn dev` 启动
2. 设置页选择下载目录
3. 在下载页粘贴 3 个测试 URL，选择不同项目，点击下载
4. 观察进度条、速度、完成通知
5. 切换到素材浏览，验证文件出现、缩略图显示
6. 关闭窗口，检查托盘图标
7. 重启应用，验证历史任务恢复
8. `yarn build` 通过
